### kicad

KiCad – Overview & Features

KiCad is a powerful, free, and open-source Electronic Design Automation (EDA) software used for designing electronic circuit schematics and Printed Circuit Boards (PCBs). It is suitable for both hobbyists and professional engineers.


Key Features of KiCad:
1. Schematic Capture (Eeschema):
Create and edit circuit diagrams.
Supports hierarchical and multi-sheet schematics.
Built-in electrical rules checker (ERC).
2. PCB Layout Editor (Pcbnew):
Design multi-layer PCBs (up to 32 copper layers).
Interactive routing and differential pair routing.
Real-time design rule checking (DRC).
Push-and-shove router for easier trace routing.
3. 3D Viewer:
Visualize the PCB in 3D with component models.
Export 3D models for enclosure design.
4. Footprint & Symbol Libraries:
Large built-in libraries of schematic symbols and PCB footprints.
Custom library creation and community library support.
5. Gerber and Manufacturing File Generation:
Export standard Gerber files, drill files, and netlists.
Supports industry-standard formats for PCB fabrication.
6. BOM (Bill of Materials) Tool:
Automatically generate BOMs for procurement.
Customizable output formats (CSV, XML, etc.).
7. Integrated Tools:
CvPcb: Assign footprints to schematic symbols.
KiCad Project Manager: Organizes and manages all project files.
8. Scripting Support:
Python scripting for automating design tasks and custom tools.
9. Cross-platform Support:
Available for Windows, Linux, and macOS.
